Python is a high-level programming language used for:
- Backend development with FastAPI and Django.
- Artificial intelligence and machine learning with TensorFlow.
- Data analysis and automation.
- APIs that connect frontend applications to backend services.

Variables and data types

A variable is a name that refers to a value. Python determines the type at runtime, so you don't need to declare it explicitly.

Important data types
Type	Example	Purpose
int	25	Whole numbers
float	45.50	Decimal numbers
str	"Python"	Text
bool	True	True/false values
NoneType	None	No value currently assigned
